Fundamental Data Structures: Stacks and Queues

This repository contains Python implementations of stacks and queues from first principles, accompanying real-world application simulations, and comprehensive error handling.

## Project Structure
- stack.py: Contains ArrayStack and LinkedStack implementations with overflow and underflow checks.
- queue.py: Contains ArrayQueue (circular buffer) and LinkedQueue (head/tail references) implementations.
- applications.py: Contains a balanced parentheses validator (using a stack) and a print spooler simulation (using a queue).
- main.py: Interactive menu-driven driver program to test all classes and scenarios.
- analysis.md: Written explanation of key design decisions for linked stacks and circular queues.

## How to Run
Ensure you have Python 3 installed. Run the interactive menu driver using:

python main.py
